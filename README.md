# 雅江洲滩数字身份证系统

**一洲一档 · 一滩一证**

雅鲁藏布江沿江洲滩信息展示页面。本阶段为一个静态网页首页。

## 一、目标用户与主要功能

### 目标用户

| 用户 | 说明 | 主要关注 |
| --- | --- | --- |
| 河道管理人员（主要） | 日常查档、台账核对、汛前核查的组织者 | 基础ID、位置、关键字段、水文期状态 |
| 一线巡查人员（次要） | 现场对照核对信息 | 名称、基础ID、位置能对得上 |
| 公众与研究者（次要） | 了解洲滩基本情况，本阶段只读浏览 | 系统简介与名录概况 |

### 主要功能

| # | 功能 | 说明 |
| --- | --- | --- |
| 1 | 系统概览 | 说明系统是什么、给谁用、数据性质；展示摘要统计 |
| 2 | 洲滩名录 | 表格展示 6 处示例洲滩：基础ID、名称、位置、类型、面积、后缀示例 |
| 3 | 身份档案示例 | 以"张家洲"为例展示不少于 8 项字段，并给出三种水文期的完整编号示例 |
| 4 | 发证与编号规范 | 基础ID 规则、动态后缀规则、字段填写规则、发证流程 |
| 5 | 页脚声明 | 演示数据说明、小组信息、更新日期 |

> 注：功能 2、3、4 为**规划内容**，当前页面尚未实现。现有页面包含系统概览与数据概况两部分。

## 四、首页打开方法

**方法一（推荐）**：下载 `index.html` 到电脑上，双击即可用浏览器打开。无需安装任何软件，无需联网。

**方法二**：若本仓库已开启 GitHub Pages，可访问：

```
https://<用户名>.github.io/<仓库名>/
```

**方法三**：在仓库文件列表中点击 `index.html` 查看源码。
